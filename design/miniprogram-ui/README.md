# 诗云小程序 UI 设计稿

设计稿按页面层级与业务名称归档，一张图片只表达一个页面或一个明确的交互状态。

## 一级页面

- 创作：创作入口
- 诗词圈：社区瀑布流
- 我的：未登录、已登录、完善用户资料弹窗

## 二级页面

- 创作：创作设置、正在创作、创作完成、退出创作保存草稿弹窗
- 诗词圈：作品详情、点赞状态、古体诗筛选、词牌筛选
- 我的：我的作品（列表、操作菜单、空状态）、我的草稿（列表、左滑删除、删除确认、空状态）、编辑资料、创作偏好、账号与安全、帮助与反馈、关于诗云、关注列表、粉丝列表

## 三级页面

- 账号与安全：退出登录确认、注销账号确认
- 帮助与反馈：意见反馈、提交成功

## 命名规则

- 默认态：`业务页面.png`
- 状态态：`业务页面-状态.png`
- 弹窗态：`业务页面-弹窗名称.png`

`参考总览` 保留旧版三联设计图，仅用于对照，不参与页面交付。
